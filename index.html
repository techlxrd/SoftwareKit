A note about using AI

As a solo developer, I want to be open about how SoftwareKit is made. Some people have called it “vibe coded,” so I thought it was worth explaining where AI has helped and where the work is still mine.

I do not see AI as a replacement for understanding the code or making the decisions. I use it as a tool when I hit a problem or need a hand with something unfamiliar, then test and refine the result myself.

  • Performance: AI helped me work through the performance improvements in version v3.2.
  • More complex features: The iPA signer and AltStore repository support were developed with AI assistance, followed by testing and debugging.
  • This landing page: AI helped with the initial design ideas, which I then revised and improved.
  • Writing: I write most of the content and use AI to help polish the English, which is not my first language.
  • CSS: I used AI as a second pair of eyes for some styling and compatibility improvements across Mac, iPad and iPhone.

AI-generated code rarely works perfectly on the first try. A lot of the work has been testing, debugging and rewriting until things behave as expected. The direction and decisions behind SoftwareKit are mine, and I continue to build and improve it myself.
